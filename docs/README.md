## 文档分层

当前 `docs/` 采用“**发布文档优先，历史文档归档**”的结构：

- `product/`：产品定位、工作流、知识模型
- `integration/`：安装、运行、客户端兼容
- `reference/`：配置、目录结构、命令参考
- `releases/`：版本说明、发布说明
- `archive/`：旧计划、旧评审、旧设计文档，保留追溯性

# 历史归档说明

- 文档类型：归档导航
- 状态：归档
- 更新日期：2026-04-07
- 适用对象：维护者、追溯者

## 为什么要归档

本目录保存的是 **历史设计、评审、计划与实施文档**。

它们不再作为当前发布版用户文档的一部分，但仍然保留，因为它们对以下场景有价值：

- 追溯系统为什么会演进成现在这样
- 回看某个架构决策最初的约束和讨论
- 对比当前实现与历史计划之间的偏差

## 使用建议

- 如果你是新用户：不需要先读这里
- 如果你是维护者：这里是理解历史上下文的入口
- 如果你在做后续架构升级：建议先读 archive，再改当前文档

## 说明

为了最大程度保留历史真实性，归档文档主体内容没有做大幅重写。

因此：

- 某些旧文档保留了当时的路径、措辞或上下文
- 某些内部链接可能仍指向它们最初所在的位置

这属于有意保留的历史痕迹，不代表当前发布文档结构。
